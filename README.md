# Task Tracker CLI

A simple command-line application built with Node.js for managing tasks.

This project allows you to add, update, delete, and track tasks using a JSON file.

## Features

* Add a new task
* List all tasks
* List tasks by status
* Update a task
* Delete a task
* Mark a task as in progress
* Mark a task as done
* Store tasks in a JSON file

## Technologies Used

* Node.js
* JavaScript
* File System (`fs`) module
* JSON
